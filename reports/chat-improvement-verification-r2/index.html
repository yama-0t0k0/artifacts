5.1　Cloud Run に設定値を渡し、無ければ起動を失敗させる

V-1 / H-7

デプロイコマンドに --set-secrets "FIREBASE_API_KEY=firebase-web-api-key:latest" を追加し、Secret Manager に値を登録します。あわせてサーバ起動時に必須設定値を検証し、無ければ起動そのものを失敗させます。現在のように「起動はするが全リクエストが401」は、障害として最も気づきにくい最悪の形です。

検証: トークン無しで 401、有効なトークン付きで 200 が返ること。0.5人日

5.2　権限変更APIを管理者限定にする

V-2

本人確認ミドルウェアの後段に管理者判定を追加し、/api/v1/auth/set-role を保護します。最初の管理者を作る経路が塞がるため、Secret Manager 管理の一時トークンによるブートストラップ経路を用意し、初期化後に削除します。

バックエンドのみの変更で、アプリの再ビルドは不要です。単独で先行リリースできます。 0.5人日

5.3　CORS ミドルウェアの追加

V-3

許可リスト方式（ワイルドカードは使わない）で CORS を実装し、パイプラインの最外側に配置します。最外側に置かないと、認証エラー(401)にCORSヘッダーが付かず、ブラウザ上では原因不明の「ネットワークエラー」に化けます。
